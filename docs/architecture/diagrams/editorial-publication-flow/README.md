## Purpose

This diagram shows how an InfraDev Academy document moves from an identified need to publication, maintenance and eventual supersession or retirement.

## Scope

The current flow covers:

- purpose, audience and scope identification;
- document-family selection;
- drafting and metadata;
- self-validation;
- review layers;
- revision and approval;
- publication;
- maintenance;
- supersession or retirement.

The exact review layers depend on the artifact family and impact.

## Current Editorial Model

The flow is based on ADR-0003, STD-001 and GUIDE-002.

Publication should occur only after required metadata is complete, findings are resolved, final status is correct and repository rendering is validated.
