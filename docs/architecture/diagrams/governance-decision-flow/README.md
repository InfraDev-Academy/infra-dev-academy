## Purpose

This diagram explains how the InfraDev Academy classifies operational work, durable Governance decisions and architectural decisions.

## Current Paths

### Operational Work

Use an Issue, task or Checklist when no durable project decision is required.

### Decision Log

Use the Decision Log for durable operational or Governance decisions that do not require a complete architectural record.

### Architecture Decision Record

Use an ADR when the decision affects structure, platform, documentation architecture, responsibilities or long-term constraints.
