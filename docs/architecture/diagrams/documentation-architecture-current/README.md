## Purpose

This diagram presents the current documentation architecture of the InfraDev Academy.

It explains how institutional direction, Governance, Architecture, execution guidance, product planning, knowledge content and releases connect.

---

## Scope

The diagram covers the major documentation responsibilities:

- Institutional Direction;
- Governance and Decisions;
- Product Direction;
- Architecture;
- Execution Guidance;
- Knowledge Products;
- Releases;
- Supporting Assets;
- Shared Vocabulary.

It does not represent every individual document.

---

## Architectural Flow

### Institutional Direction

Official Publications and living Academy documents define the project's institutional direction.

### Governance and Decisions

Governance, the Decision Log and ADRs preserve authority, decisions and architectural reasoning.

### Product Direction

PRDs, the Roadmap and release scope define which problems and outcomes the project prioritizes.

### Architecture

Architecture documents define structural responsibilities, boundaries and relationships.

### Execution Guidance

Standards, Guides, Frameworks, Templates and Checklists translate decisions into repeatable practice.

### Knowledge Products

Knowledge domains, Learning Paths, the Glossary and Community support transform project direction into learner-facing value.

### Releases

Releases preserve validated, versioned outcomes and their review evidence.

---

## Source of Truth

The authoritative meaning of each collection remains in:

- its collection README;
- accepted ADRs;
- active Governance documents;
- active Standards and Guides;
- release records.

This diagram is a navigation and architecture aid.

## Maintenance

Update this diagram when:

- a documentation collection changes responsibility;
- a new document family becomes active;
- Governance changes the relationship between planning, execution and publication;
- the release architecture changes;
- a related ADR supersedes the current model.
