# Guides

The Guides collection provides practical instructions for interacting with, contributing to and maintaining the InfraDev Academy ecosystem.

While Standards define official requirements, Guides explain how those requirements should be applied in real workflows.

---

## Purpose

This collection exists to help readers and contributors understand how to participate in the InfraDev Academy.

Guides translate institutional principles, architectural decisions and Standards into practical actions.

They support:

- contributor onboarding;
- editorial workflows;
- document creation;
- review processes;
- repository navigation;
- collaboration;
- maintenance activities.

---

## Scope

The Guides collection contains operational and instructional documents.

A Guide should explain how to perform a process without replacing the authority of an active Standard, Architecture Decision Record or Governance document.

Guides may include:

- procedures;
- recommendations;
- examples;
- checklists;
- workflows;
- references to Standards;
- explanations of project conventions.

---

## Available Guides

### GUIDE-001 — Contributor Guide

Explains how contributors can participate in the InfraDev Academy, propose changes, create documents and collaborate responsibly.

### GUIDE-002 — Editorial Handbook

Explains how editors and authors should apply the Editorial Standard during the creation, review and publication of documents.

---

## Relationship with Other Collections

### Standards

Standards define mandatory requirements.

Guides explain how to apply those requirements.

### Architecture Decision Records

ADRs explain why significant structural decisions were made.

Guides should remain compatible with accepted ADRs.

### Governance

Governance documents define authority, responsibilities and decision-making processes.

Guides describe the practical workflows that operate within those rules.

### Official Publications

Official Publications communicate the institutional identity of the InfraDev Academy.

Guides support the people responsible for creating and maintaining those publications.

---

## Navigation

New contributors should begin with:

1. GUIDE-001 — Contributor Guide
2. README files for the collections they intend to modify
3. Relevant active Standards
4. Applicable Governance documents
5. GUIDE-002 — Editorial Handbook, when producing or reviewing publications

---

## Maintenance

Guides should evolve as project workflows mature.

Changes must remain aligned with:

- accepted ADRs;
- active Standards;
- project Governance;
- repository structure;
- current contributor workflows.

A Guide must not introduce a new mandatory requirement without support from the appropriate Standard or Governance document.

---

## Final Statement

Standards define expectations.

Guides transform those expectations into understandable and repeatable actions.
